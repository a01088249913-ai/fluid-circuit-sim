# 공유압 회로 시뮬레이터

**제작자:** 한국폴리텍대학 진주캠퍼스 자동화과 장성욱

설비보전기사 실기(과정평가형) 공개문제 2026.05.08 수정본 16문제(공기압 8, 유압 8)를 연습하는 웹 시뮬레이터입니다.

- **1. 회로 구성** — 부품 배치·배관 연결(실물/기호 보기), 실습 장비 사진 위 전기 배선, 정답 도면과 단자 번호 안내
- **2. 기본동작** — 전기회로도 오류 정정(a/b 접점, 신호 이름, 분기·합류점 위치), PB1 2회 동작 자동 채점
- **3. 유지보수** — 카운터·비상정지·타이머·압력스위치 등 변경 회로 동작 확인, 유지보수 배관 검사
- **모의시험** — 무작위 문제, 60분 타이머, 기본동작·유지보수 평가 각 1회, 결과표
- **랜덤 오류 문제** — 정답 회로에 오류를 무작위로 심어 매번 새 문제
- 압력 설정(서비스 유닛·릴리프·감압·카운터밸런스·압력스위치), 리밋스위치 방향성, 문제별 완료 표시
- 릴레이 5ms · 솔레노이드 30ms 응답 지연, 실린더 1행정 2초

`index.html` 한 파일로 동작합니다. GitHub Pages(Settings → Pages → Branch: main, / root)로 켜면 바로 열립니다.

정정 예시와 유지보수 회로는 시뮬레이터에서 2회 연속 정상 동작을 확인한 하나의 답이며, 공식 정답과 다를 수 있습니다.
